Ramadan Widget

Home Screen Widget for iPhone

1
Install the free Scriptable app
2
Tap Copy Script below, then open Scriptable → tap + → paste → name it "Ramadan"
3
Go to home screen → long press → + → search Scriptable → add Medium widget
4
Long press the widget → Edit Widget → set Script to "Ramadan"
Open Scriptable

Requires iOS 14+ and the free Scriptable app.
Widget shows prayer times, sun arc, and Eid countdown.
