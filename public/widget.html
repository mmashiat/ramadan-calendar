Ramadan Widget

Home Screen Widget for iPhone

1
Install the free Scriptable app from the App Store
2
Tap the button below to add the widget script to Scriptable
3
Long press your home screen → + → search Scriptable → add Medium widget
4
Long press the widget → Edit Widget → set Script to "Ramadan"
Add Widget to Scriptable Or copy script manually

Requires iOS 14+ and the free Scriptable app.
Widget shows prayer times, sun arc, and Eid countdown.
